# whitebox_scene_studio · 白膜场景生图工作台

## 一句话
左边用最基础的 3D 体块搭一个"白膜"场景，右边把白膜图 + 语义分割图当参考图喂给图生图模型，
让出图的相机角度、构图、物体位置稳定可控——把"抽卡"变成"摆位"。

## 要解决的业务问题
文生图最不稳的一环是空间。你说"人在左、车在右、镜头压低到膝盖高度"，模型每次给的都不一样。
行业解法是给模型一张结构参考图（ControlNet 那一套），可普通人手上没有这张图——
要么去建模，要么去找一张构图恰好一致的照片。

这个工具把那张图变成十几秒就能搭出来的东西：拖几个方块、圆柱、胶囊，摆成人、车、楼、树，
转到你要的机位，按一下快照，得到两张严格对齐的参考图：

- **白膜图 (clay)**：统一白色材质 + 柔光。交代体积、透视、遮挡关系、构图。
- **语义分割图 (seg)**：每类物体一个纯色块，无光照。交代"哪块是人、哪块是车"。

再加一段系统自动生成的**色卡图例**（"红色=人物×3，蓝色=车辆×1，绿色=植被×5"），
一起喂给火山方舟 Seedream。出图就按你摆的来。

## 分区

### 左：3D 白膜编辑器
- **体块库**：方块 / 球 / 圆柱 / 圆锥 / 胶囊 / 平面 / 楼梯块
- **语义类别与固定色卡**（每个物体必有一个语义）：
  | 语义 | 颜色 | 典型用途 |
  |---|---|---|
  | ground 地面 | #4A4A4A | 地板、路面 |
  | building 建筑 | #B03A2E | 楼房、墙体块 |
  | wall 墙面 | #95A5A6 | 隔断、围墙 |
  | person 人物 | #E74C3C | 胶囊立人 |
  | vehicle 车辆 | #2980B9 | 轿车、卡车方块 |
  | vegetation 植被 | #27AE60 | 树、草丛 |
  | furniture 家具 | #F39C12 | 桌椅柜 |
  | prop 道具 | #8E44AD | 杂物 |
  | water 水面 | #1ABC9C | 河、池 |
  | light 光源 | #F1C40F | 灯、窗 |
- **操作**：体块库拖到地面放置 / 点选 / 平移旋转缩放（gizmo）/ 复制 / 删除 /
  贴地吸附 / 网格吸附 / 撤销重做
- **相机**：轨道旋转、平移、推拉；机位预设（人眼 1.6m、低机位 0.4m、高机位 3m、俯瞰）；
  FOV 滑杆；画幅比锁定 1:1 / 16:9 / 9:16 / 4:3
- **取景框**：画面里画出出图画幅的安全框，所见即所得
- **快照**：同一相机一次出 clay / seg / depth 三张严格对齐的图

### 右：生图台
- **参考图槽**：clay 与 seg 自动占两格；用户可再加最多 4 张（风格参考、角色参考）；每张单独开关
- **主提示词**：大文本框
- **自动图例**：系统按场景生成，可折叠可编辑，默认拼在提示词前面
- **参数**：模型 / 尺寸 / 张数
- **结果**：网格预览、大图、下载
- **叠加对比滑杆**：生成图与白膜图叠在一起拉滑杆，一眼看出构图有没有跟住（这是这个工具的验收方式）
- **历史**：每次生成落盘，可回看

## Agent 接口（人指挥 agent 摆世界）
全部走 `frago recipe run whitebox_scene_studio --params '{"action": "...", ...}'`。
场景真值在磁盘 JSON，页面轮询同步——所以 agent 改了场景，人的浏览器里立刻动；人拖了物体，agent 下一次读就看得到。

| action | 干什么 |
|---|---|
| `view` | 发布页面状态，返回 url（默认动作） |
| `scene_get` | 场景真值：物体清单（id/形状/语义/标签/位姿/包围盒）+ 相机 |
| `object_add` / `object_update` / `object_delete` / `scene_clear` | 增改删清 |
| `place` | **语义化放置**：{shape, semantic, relative_to, direction: front/back/left/right, distance, align: ground} → 服务端算世界坐标 |
| `measure` | 两物体距离、相对方位、AABB 是否相交 |
| `validate` | 纯几何体检：穿模、悬空、出画 |
| `camera_set` | 直接给位姿，或给 preset + 目标物体 |
| `camera_frame` | **世界空间求解**：给一组物体，解出能把它们全框住的相机位姿 |
| `snapshot` | 渲染出图，返回三张图绝对路径（走页面握手） |
| `critique` | **截图自识别**：把快照交给多模态模型，回结构化质量判断 + 改进建议 |
| `generate` | 生图（复用 doubao_seedream_image） |

## 复用
- 生图：`doubao_seedream_image` 配方（火山方舟 Seedream，支持多参考图数组）
- 凭证：不自己配 key，subprocess 调子配方，runner 按子配方名注入
- 前端 3D：three.js r165，**本地 vendor 进 assets/**，不吃 CDN
